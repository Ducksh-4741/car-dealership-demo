# 🚗 Car Dealership Demo Website

A fully responsive car dealership website with:

## ✨ Features
- Modern UI design
- Vehicle search & filtering
- Interactive vehicle modal
- 3D Car Viewer using Three.js
- Responsive layout
- Smooth scrolling navigation

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- Three.js (3D Viewer)

## 📌 Purpose
This is a front-end demo project built to showcase UI/UX and JavaScript skills.
